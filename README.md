# Data Quality Audit – Superstore

## 📌 Project Overview

This project focuses on auditing a Superstore dataset using Python and Pandas. The main purpose is to identify common data quality problems such as missing values, duplicate records, invalid ranges, and consistency issues.

## 🎯 Objective

To create a repeatable data quality checklist that can be used to validate a dataset before performing further analysis.

## 🛠️ Tools Used

- Python
- Pandas
- Excel

## 🔍 Quality Checks Performed

The dataset was checked for:

- Missing values
- Duplicate rows
- Duplicate Product IDs
- Invalid Product ID formats
- Invalid dates
- Date range issues
- Invalid quantity values
- Discount range issues
- Invalid sales values
- Invalid categories
- Invalid regions
- Invalid customer segments
- Category and Sub-Category consistency
- Product mapping consistency

## 📊 Dataset

The project uses a Superstore sales dataset containing **1000 records and 13 columns**, including Product ID, Product Name, Category, Sub-Category, Order Date, Region, State, City, Segment, Quantity, Discount, Sales, and Profit.

## 📁 Project Files

- `data_quality_audit.py` – Python script used for the audit
- `audit_report.csv` – Summary of audit results
- `issue_log.csv` – List of identified data quality issues
- `validation_rules.csv` – Data validation rules
- `cleaned_sample.csv` – Cleaned dataset sample
- `Data_Quality_Audit_Report.xlsx` – Complete audit report
- `Superstore_Product_Count_Analysis.xlsx` – Original dataset

## ✅ Audit Result

A total of **26 validation checks** were performed.

**Issues Found: 0**

The dataset passed the defined data quality checks successfully.

Through this project, I learned how to use Python and Pandas to validate datasets, identify potential data quality problems, create reusable validation rules, and prepare clean data for further analysis.
